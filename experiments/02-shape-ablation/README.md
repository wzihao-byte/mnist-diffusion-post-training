# 数字扩散模型字形对照实验

这组实验检查原项目的两个问题，分别是「0」斜和「2」笔画偏淡。测试了放大原始字形、重采样困难「2」、修改监督损失和在 RL 中加入字形奖励。另从原来的 SFT → RL → OPD 权重出发，比较等步数的普通 RL 与字形 RL，验证可直接使用的修订权重。

## 结论

推荐 `post_shape_low_lr16`。原链路追加 360 步字形 RL，学习率从 0.00016 降到 0.00008。两个训练种子上，「0」直立通过、「2」可读且笔画足量以及其他数字的通过率，均高于原链路。平均「0」绝对倾斜角中位数从 10.26° 降到 2.95°，此角度对联合通过的「0」计算。附带示例图取种子 143。

| 原链路比较 | 「0」直立 | 「2」可读且笔画足量 | 其他数字通过 |
| --- | ---: | ---: | ---: |
| 原 SFT → RL → OPD | 47.57% | 79.51% | 91.93% |
| 追加普通 RL | 51.39% | 92.71% | 95.40% |
| 追加字形 RL | 99.31% | 88.19% | 94.88% |
| 追加字形 RL，半学习率 | 95.83% | 97.57% | 96.61% |
| 追加字形 RL，加强 KL | 90.28% | 95.49% | 96.14% |

普通追加 RL 已改善「2」，提升直立度主要来自字形奖励。直接追加字形 RL 时，种子 143 的「2」笔画足量通过率为 76.39%，低于原链路 80.56%。半学习率和加强 KL 分别在单项对照中缓解了这类波动。半学习率和普通追加 RL 的对比同时涉及学习率和奖励变化，其差值用于评估整套配方。

| 单项改动 | 对照与结果 |
| --- | --- |
| 32×32 画布 | 对 16×16 SFT，「2」亮像素面积中位数由 18.50 升至 20.75，「2」OCR 可读率由 89.93% 降至 81.60%。在本次固定网络参数量和更新次数下，画布扩大保留了更多细节，识别表现仍依赖后训练。 |
| 困难「2」增采样 | 「2」可读率 89.93% → 78.47%，可读且笔画足量 70.83% → 47.57%。种子 143 中，这批低置信样本的亮像素均值约 15.9，剩余「2」约 21.8。 |
| 前景加权 | 「2」可读且笔画足量 70.83% → 85.42%，单看 OCR 识别则为 89.93% → 85.42%。其他数字通过率从 82.86% 降至 77.95%。 |
| 边缘损失 | 「2」可读且笔画足量 70.83% → 76.39%，其他数字通过率 82.86% → 86.72%。两组种子方向一致。 |
| 字形奖励 | 在 SFT 后的等设置 RL 中，16×16 的「0」直立通过 42.01% → 94.44%，32×32 上 43.06% → 93.75%。两种分辨率的「2」笔画足量指标均略升。 |

这是两个训练种子的受控实验。更高分辨率的不同训练预算、困难样本的其他选择规则与更广泛的视觉审美仍属于未测试的配置。

## 运行已有权重

使用 Python 3.12。推理可用 CPU、MPS 或 CUDA，运行已有权重时无需 MNIST 文件。

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python sample.py --stage post_shape_low_lr16 --prompt 'red 0 on the left' --out demo/zero.png
python sample.py --stage post_shape_low_lr16 --prompt 'green 2 on the right' --out demo/two.png
```

`original_full` 对应原项目完整链路，`post_control16` 对应原链路追加普通 RL，`post_shape16` 对应原链路追加字形 RL。`post_shape_low_lr16` 和 `post_shape_high_kl16` 分别减半学习率和提高 KL 系数。`sft32`、`rl_control32` 和 `rl_shape32` 以 32×32 生成。推理取样由种子决定，同一批次设置下可复现。

## 对照条件

| 方法 | 对照 | 改动 |
| --- | --- | --- |
| 大画布 | `sft16` 对 `sft32` | 原始 28×28 字形分别直接缩到 12×12 和 24×24，放进 16×16 和 32×32 画布。网络参数数目和更新次数相同，全程用相应分辨率预训练及微调。 |
| 困难「2」 | `sft16` 对 `hard2` | 用旧奖励分类器在训练集筛出「2」置信度最低的 25%，替换一半原本抽到的「2」样本。保留其他数字的采样和「2」总次数。 |
| 前景加权 | `sft16` 对 `foreground` | 监督 MSE 按真实像素亮度乘以 `1 + 3 × pixel`，再按平均权重归一化。 |
| 边缘损失 | `sft16` 对 `edge` | 在原像素 MSE 上，加 0.35 倍的横纵相邻像素差误差。 |
| 字形奖励 | `rl_control16` 对 `rl_shape16`，另在 32×32 重做 | 向「0」加直立奖励，向「2」加连通度、底笔支撑与墨迹量联合奖励。两组都用 360 步、相同「0」「2」采样比例和相同起点。32×32 用同一个降采样后的旧奖励读数。 |
| 完整链路验证 | `post_control16` 对 `post_shape16` | 两组都从同一个 SFT → RL → OPD 检查点开始，追加 360 步 RL，唯一改动是字形奖励。 |
| 形状 RL 稳定性 | `post_shape16` 对低学习率与高 KL 分支 | 一组把学习率从 0.00016 降到 0.00008，另一组把约束初始检查点的 KL 系数从 0.10 提至 0.30。其他设置沿用 `post_shape16`。 |

两个训练种子分别为 143、144。同一种子内，监督微调各分支用相同划分和训练步数。RL 中每批八组提示有两组固定为「0」、两组固定为「2」，其余随机。字形奖励经旧奖励分类器的目标类置信度加权。

## 指标与原始记录

每个检查点、每个训练种子生成 60 条提示 × 12 次抽样 × 2 个采样种子，共 1,440 张图，每个目标数字有 144 张。比较复用同一组提示和噪声。跨分辨率时，以同一个 32×32 高斯噪声场为起点，16×16 取独立 2×2 块平均后乘 2，从而保持标准正态方差。

同一训练种子内共用一个独立 OCR 评估器。评估器用另划出的 6,000 张真实 MNIST 字形训练，混合两种分辨率。训练奖励沿用原项目的另一套分类器。

- **「0」直立通过**要求数字、颜色和位置均正确，且笔画重心估算的绝对倾斜角 ≤10°。
- **「2」可读**指独立 OCR 识别为「2」且前景量足够。
- **「2」可读且笔画足量**额外要求颜色与位置正确，亮度 ≥0.50 的像素面积折算到 16×16 后至少为 15。该指标是笔画量代理，样图用于观察线条和字形。
- **其他数字通过**对「0」「2」以外的数字检查识别、颜色和位置。

`reports/143` 和 `reports/144` 各有逐张记录 `shape_samples.csv`、汇总与采样置信区间 `shape_metrics.json`，以及固定提示前两张样本的对照图。`reports/summary.json` 汇总两个训练种子。配对区间衡量固定模型下的采样波动，训练结论同时参考两个种子的方向。

## 重新训练和评估

`reference/` 包含每个种子的原项目基线、奖励分类器和完整链路权重。首次训练自动下载并校验 MNIST。

```bash
for seed in 143 144; do
  python ablate.py --seed "$seed" --original "reference/$seed" --data-dir data \
    --run-dir "reproduced/$seed" sft16 hard2 foreground edge sft32 \
    rl_control16 rl_shape16 rl_control32 rl_shape32 post_control16 post_shape16 \
    post_shape_low_lr16 post_shape_high_kl16
  python score.py --original "reference/$seed" --data-dir data \
    --run-dir "reproduced/$seed" --out "reproduced_reports/$seed"
done
python aggregate.py reproduced_reports/143/shape_metrics.json \
  reproduced_reports/144/shape_metrics.json --out reproduced_reports/summary.json
```
